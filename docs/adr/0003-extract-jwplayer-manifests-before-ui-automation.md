# Extrair Manifestos JWPlayer e Faixas de Legenda Antes de Automação de UI

Para vídeo-aulas hospedadas em players embarcados (como o JWPlayer no Skilljar via `<sjwc-video>` ou `videoJsArgs` / `botr_*_div`), priorizamos a extração direta das faixas `.srt`/`.vtt` através do manifesto HTTP da API v2 do JWPlayer (`cdn.jwplayer.com/v2/media/<mediaId>`) e de elementos `<track>` no DOM, priorizando faixas em português (`pt-BR`/`pt`, inclusive quando identificadas apenas por `label: "Portuguese"`) com fallback para inglês (`en`). Interagir com os botões de CC do player via Playwright ou reproduzir o vídeo em tempo real é lento, frágil diante de Shadow DOM e iframes, e frequentemente retorna apenas a legenda do instante atual; o download direto do manifesto entrega todos os segmentos com timestamps precisos e a duração real do vídeo em milissegundos.
